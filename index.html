Über das Projekt

Flappy Semester ist ein Canvas-basiertes Browser-Game mit Missionssystem, Progression, freischaltbaren Charakteren und dynamischer Gegner-Sabotage.

Features

  • Canvas Game Loop
  • Missionen & Kaffee-Progression
  • freischaltbare Charaktere
  • Gegner-Sabotage
  • localStorage-Speicherung
  • responsive UI

Tech Stack

  • HTML5 Canvas

  • localStorage
